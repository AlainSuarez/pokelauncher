# Instrucciones del proyecto

Este es un proyecto personal de hobby. Priorizar cambios simples, útiles y un uso moderado de tokens.

## Pruebas

- No crear, escribir, ampliar ni modificar tests automatizados.
- No añadir frameworks, dependencias ni infraestructura de tests.
- No ejecutar suites de tests por iniciativa propia.
- Verificar los cambios con revisiones puntuales y comprobaciones manuales proporcionales al cambio.
- Solo realizar trabajo sobre tests si el usuario lo solicita explícitamente.

## Entorno Python

- No crear ni utilizar entornos virtuales (`venv`, `.venv`, virtualenv, etc.).
- Usar el Python disponible en el sistema para ejecutar la aplicación.
- Documentar la instalación de dependencias sin pasos de creación o activación de entornos virtuales.
- No forzar instalaciones sobre un Python administrado por el sistema ni usar `--break-system-packages` sin indicación explícita del usuario.
